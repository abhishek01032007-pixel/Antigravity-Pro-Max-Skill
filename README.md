## 🌟 Overview

**Antigravity Pro Max Skill** is a professional skill library for **Google Antigravity** that helps you activate advanced skill packs only when needed.

It is built for developers who want better control over:

- 🎨 **Frontend Development**
- 🗄 **Backend Development**
- 🧪 **QA / Debugging**
- 🔗 **Full Stack Development**

Instead of loading everything globally, this system keeps skills **project-scoped**, so only the selected project gets the required Pro Max skills.

---

- ✅ **One-command setup**
